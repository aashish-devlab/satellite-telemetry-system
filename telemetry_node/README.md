# Satellite Telemetry System
## Overview

The Satellite Telemetry System is an ESP32-based embedded project that simulates a satellite telemetry subsystem. It collects real-time sensor data, processes telemetry, displays system status locally, and prepares the data for transmission to a ground station.

The project focuses on embedded firmware development, sensor integration, telemetry packet design, and system documentation.

## Hardware

- ESP32 DevKit V1
- MPU6050 (IMU)
- BMP280 (Pressure & Altitude Sensor)
- SSD1306 OLED Display
- 18650 Li-Ion Battery
- TP4056 Charging Module
- XL6009 Boost Converter
